# System Requirements

## 1. Hardware Requirements
- Arduino Microcontroller Board (Uno/Nano or compatible)
- IR / Proximity Sensors (3 units for slot detection)
- LED Indicators (3 units)
- Piezoelectric Buzzer
- Jumper Wires (Male-Male / Male-Female)
- Breadboard (for prototyping)
- Regulated 5V Power Supply

## 2. Software Requirements
- Arduino IDE (for code compilation and upload)
- Embedded C/C++ programming support
- USB Driver compatible with Arduino board

## 3. System Specifications
- Minimum 256 MB RAM (4 GB recommended)
- 10 GB available disk space
- USB Port for hardware interface

## 4. Operating System Compatibility
- Windows 10/11
- Linux (Ubuntu recommended)
- macOS
